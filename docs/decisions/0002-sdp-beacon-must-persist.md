# 0002 蓝牙 SDP 信标必须常驻

日期：2026-11-18
状态：已采纳

## 背景

车机判断「这台手机算不算 CarPlay 设备」依赖配对那一刻读到的 SDP 记录
（`2d8d2466` / `deca-fade` / `cade-defa` / `02030302`）。之后它一直使用缓存。
信标一旦消失，车机不再重新读取，桌面的 Apple CarPlay 会一直是灰的。

## 决策

- 用前台服务常驻注册 SDP 信标（`SdpBeaconService`），每 10 秒自检；
- 线程死亡或记录不全时自动重挂；
- 不把「注册成功」当成一次性动作，而是持续状态。

## 后果

- 手机侧「清除配对」后必须重新走配对流程（车机缓存旧 link key）；
- 换版本或换配对后，建议重启车机再配；
- 任何优化都不能把信标改成按需注册。

## 证据

README 的使用步骤（先在车机上删设备、再重配对）；`SdpBeaconService` 的自检与重挂逻辑。
