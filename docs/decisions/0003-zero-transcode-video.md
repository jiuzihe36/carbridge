# 0003 视频零转码转发

日期：2026-11-18
状态：已采纳

## 背景

Car+ 在本机已经输出 H.264 Annex-B。若在手机里再解码/编码一次，会带来延迟、
发热和画质损失，且中低端机可能扛不住。

## 决策

- 按帧把 Car+ 的 H.264 直接封进 AirPlay 视频通道，不做二次编码；
- 分辨率、帧率优先取车机 `/info` 与 iAP2 上报值，`CarProfile` 只做兜底；
- 自适应判据是「不低于目标帧率」，不要求严格相等。

## 后果

- 上游（Car+）的编码参数直接决定画质与带宽占用；
- 帧率上限放开到 120，但实测 Car+ 交付上限约 30fps —— 瓶颈不在本机转发；
- 不做转码意味着不能靠转码「修复」上游异常码流，只能在上游解决。

## 证据

`carplay/bridge` 的封帧路径；实车画面；帧率判据相关提交。
