# 0004 MFi 鉴权：默认宽松，严格模式可选

日期：2026-11-18
状态：已采纳（严格模式的实车验证仍是 OPEN）

## 背景

部分车机 `CONF_AUTHENTICATION=false`，即不校验签名也继续会话；也有车机要求完整
MFi 验签。两种行为都存在。

## 决策

- 默认**宽松模式**：仍做「探测性验签」并把结果写进会话日志，但不阻断会话；
- 提供严格验签开关（`Iap2SenderSession`），需要时打开；
- 假车机侧改为真 RSA，能在本地跑通完整验签链路。

## 后果

- 宽松模式兼容面更大，但**不能宣称已通过严格 MFi 认证**；
- 遇到要求严格签名的车机，需要实车日志确认失败点后再切换模式；
- 该事项在 `docs/STATUS.md` 保持 `OPEN`，直到有对应实车证据。

## 证据

`Iap2SenderSession` 的宽松/严格分支与探测性验签日志；假车机 RSA 验签；实车通行记录。
